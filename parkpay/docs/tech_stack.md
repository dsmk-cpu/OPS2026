# Technology Stack
ParkPay is implemented as a TypeScript monorepo with separate backend and frontend applications.

## Backend
- Node.js 24
- TypeScript
- Express
- TypeORM
- SQLite
- Stripe SDK
- Vitest
- Supertest
- Zod
- Pino
- Helmet
- express-rate-limit

## Frontend
- React 19
- TypeScript
- Vite
- CSS
- Playwright for end-to-end testing
